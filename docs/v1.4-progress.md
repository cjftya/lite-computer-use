## Known limits

- The stateless CLI cannot enforce a host-wide retry count; the skill instructs the host to stop identical repeats and allows one cause-resolving alternate route.
- Shell dispatch acceptance cannot prove document or page load completion.
- Search budgets are cooperative and cannot interrupt an individual blocking network filesystem call.
- No Windows UI result is claimed from Linux mocks.
- The reported 30-retry incident has no preserved trace, so these code defects are not claimed as its proven direct cause.
